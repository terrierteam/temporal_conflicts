# Temporal Conflicts in LLMs

This is a repository for the paper "Temporal Conflicts in LLMs: Reproducibility Insights from DYNAMICQA and MULAN"

In this study we reproduce experiments from [DYNAMICQA](https://github.com/copenlu/dynamicqa) and [MULAN](https://github.com/coastalcph/fact_mutability). We use the original implementations for both, with modifications wherever described in our paper.
